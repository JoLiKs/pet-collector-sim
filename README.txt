Веб-версия «PetCollectorSimulator», собранная roblox2web 2.2.0.

Luau-скрипты игры транспилированы в JavaScript (game.bundle.js) и выполняются в браузерном эмуляторе Roblox (runtime.js, three.js в vendor/).
Запуск: любой статический сервер, например  python3 -m http.server  и открыть http://localhost:8000/ (файл по file:// тоже обычно работает).
Подробности и список неподдержанных API: CONVERSION_REPORT.txt.
