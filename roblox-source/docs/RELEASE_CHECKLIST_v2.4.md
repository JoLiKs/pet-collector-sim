# Предрелизная проверка Pet Collector Simulator v2.4

Дата: 07.10.2026, Минск. Ревизия: v2.4 (Config.VERSION 2.4.0), локальный репозиторий. Проверка — только отчёт: по её итогам ничего не исправлялось.
Пометки: **проверено** — прогоном (тесты, эмулятор, Chromium) или однозначно по коду/файлам; **не проверить без Studio** — эмуляция этого не моделирует.

## Вердикт: **готова с оговорками**

В коде не нашлось ошибок, которые мешают запуску: все автоматические проверки зелёные, демо-флаги выключены, нулевые ID ничего не ломают, отладочных команд у игроков нет. Но игра **ни разу не запускалась в настоящей Roblox Studio**, а для публичного запуска не хватает того, что может сделать только Егор: ID покупок, иконка и превью, анкета рейтинга, ручной прогон в Studio. Есть один вопрос соответствия правилам о платных случайных предметах: шансы для билетов на яйца в «Рынке» (§3.6). Его стоит закрыть до включения продажи гемов.

## 1. Блокеры публичного запуска

Технических блокеров в коде не найдено. Публиковать как **Public** нельзя, пока не сделано:
1. **Ручной прогон в Studio** (§5): игра ни разу не стартовала в настоящем движке. Эмулятор и тесты покрывают серверную логику и интерфейс, но не физику, рендер, репликацию и мобильный клиент Roblox.
2. **Анкета возрастного рейтинга** (Content Maturity) — без неё Roblox не даёт открыть игру публично. Отвечайте честно (§4).
3. **Шансы для билетов на яйца в «Рынке»** (§3.6) — решить до включения продажи гемов за Robux: показать шансы на карточке билета или продавать билеты только за монеты.

Не блокеры, но без них запуск будет слабым: иконка и превью (§4), ID покупок (§3.3; без них магазин показывает «Скоро»).

## 3. Пункты проверки

### 3.1 Place-файл запускается без ошибок — ⚠ частично проверено
- `PetCollectorSimulator.rbxl` (310 838 байт ≈ 304 KiB, собран `rojo build`) прочитан парсером бинарного формата: 13 классов, 109 инстансов, 97 скриптов (1 Script, 4 LocalScript, 92 ModuleScript). Это совпадает с `PetCollectorSimulator.rbxlx` (739 314 байт ≈ 722 KiB) и эталоном Rojo.
- Тот же код без ошибок выполняется в эмуляторе (интеграционный сценарий, браузер).
- **Не проверить без Studio:** что движок открывает файл и запускает скрипты без ошибок в Output. Мир строится скриптом `WorldBuilder` во время игры, поэтому в режиме Edit сцена почти пустая — это нормально.

### 3.2 Демо-флаги в боевом Config выключены — ✅ проверено
- `DEMO_BOT_ENABLED = false` (Trader Tom: сделки с ботом и бот-«друг»), `DEMO_BOTS = false` (боты «Суперсилы»), `STUDIO_GRANT_ALL_PASSES = false`, `DISABLE_STATION_CHECK = false`.
- Демо-значения подставляются только при сборке веб-демо патчами `roblox2web.config.json`; в `.rbxlx` и `.rbxl` их нет (проверено поиском по файлу).
- `STUDIO_FALLBACK_TO_EPHEMERAL = true` действует только в Studio (`RunService:IsStudio()`), в опубликованной игре — нет.
- Сервер отклоняет `TradeStartBot` при выключенном флаге; кнопка сделки с NPC скрыта. NPC Том в хабе остаётся и открывает окно обмена с игроками.

### 3.3 ID геймпассов и продуктов = 0 — ✅ проверено, с оговоркой
- Все 5 геймпассов и 9 продуктов в `Config.lua` равны 0. Магазин показывает «Скоро», цены не запрашиваются, нажатие — тост; премиум пропуска и «+5 уровней» в «Рынке» тоже обрабатывают 0. Ошибок нет (Chromium, сборка без патчей).
- **Оговорка:** тост при нажатии — текст для разработчика: «Пока недоступно: укажите ID в ReplicatedStorage/Shared/Config» (так же для пропуска). Если опубликовать без ID, игроки увидят его. Заполните ID до публикации или считайте это временным.
- `ProcessReceipt` для неизвестного ID пишет `warn` и возвращает `NotProcessedYet`, Roblox повторит чек.

### 3.4 DataStore без API Services — ✅ проверено (эмуляция)
- В Studio при ошибке «Studio access to APIs is not allowed» загрузка сразу переходит в режим без сохранения (тест «Studio без API Services — мгновенный переход»), при прочих отказах — после повторов (тест «в Studio при отказе DataStore включается режим без сохранения»). В Output — `warn` «Using temporary data».
- В опубликованной игре переключатель не нужен; при недоступном DataStore игрока кикают с понятным сообщением, а чужую блокировку (упавший сервер) загрузка ждёт до 180 с, а не кикает сразу (v2.4).
- **Не проверить без Studio:** точный текст ошибки на текущей версии Studio (код ищет подстроки «studio access to apis» / «enable studio access»). Если текст другой, будут повторы с ожиданием до 15 с на попытку, а потом всё равно режим без сохранения.

### 3.5 PolicyService и платные случайные предметы — ✅ проверено по коду, ⚠ оговорка
- `PolicyService:GetPolicyInfoForPlayerAsync` вызывается при входе, 3 попытки. При ошибке и до получения ответа игрок считается ограниченным — это безопасная сторона.
- Ограниченным скрываются наборы гемов, монет и удачи в магазине (видна плашка «недоступны для вашего аккаунта или региона»). На сервере не действуют платные модификаторы удачи (бусты, бонус VIP). Торговля отключается при `IsPaidItemTradingAllowed = false`.
- **Оговорка (риск):** ограничение покупки валюты — только в интерфейсе. Если покупку продукта вызвать в обход UI (эксплойт клиента), `ProcessReceipt` выдаст гемы и ограниченному игроку.
- **Оговорка (политика):** геймпасс x2 монет и VIP не скрываются: монеты и бонусы из них косвенно идут на яйца. Сверьте с актуальными правилами Roblox о платных случайных предметах.

### 3.6 Шансы для покупок за Robux и гемы — ⚠ оговорка
- Яйца (за монеты; Crystal Egg — 75 гемов, Lunar Egg — 120 гемов): подсказка у яйца открывает окно с численными шансами каждого питомца с учётом удачи, а также шансами Golden (2%) и Rainbow (0.2%) — **до** покупки. Проверено по коду (`EggPanel`, `PetService` → `OpenEgg`).
- Слияние с катализатором (катализатор продаётся за гемы): окно слияния показывает шансы «сразу Shiny / повышение / без изменений» с учётом катализатора, формула общая с сервером (С13, тест).
- Бусты удачи за Robux: текущая удача видна в HUD («Удача x1.00») и в окне яйца.
- **Пробел:** «Рынок» продаёт билеты на яйца за гемы (например, Frost Egg Tickets ×2 за 60 гемов), а на карточке билета шансов нет. Они видны только в окне яйца, когда билет уже куплен. Гемы продаются за Robux, так что билеты — платный случайный предмет. До продажи гемов покажите шансы на карточке (или ссылку на окно яйца) либо переведите билеты на монеты.

## 6. Риски, которые не проверить без Studio и живых игроков

- Игра ни разу не запускалась в настоящем движке; возможны мелкие ошибки раскладки и поведения, которые эмулятор не воспроизводит (физика, рендер, `ScaleTo` на R15, ProximityPrompt на таче).
- Общие ресурсные узлы на полном сервере (С7), трафик `State` (С8), рывки врагов (С9) — не исправлены, масштаб неизвестен.

- Античит скорости с новым порогом может давать ложные кики при сильных лагах (порог ≈ 36 студ/с для базовой скорости 16).
- Политики Roblox о платных случайных предметах и анкета меняются — сверить перед запуском.
